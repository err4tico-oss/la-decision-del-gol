# La decisión del gol

Página estática lanzada como sitio web para GitHub Pages, inspirada en el juego de draft y torneo de fútbol que venía dentro del ZIP.

## Archivos principales

- `index.html` — estructura de la página
- `styles.css` — estilo visual y diseño del juego
- `script.js` — interacción mínima para el menú y decisiones
- `.github/workflows/pages.yml` — despliegue automático a GitHub Pages

## Producción

El sitio se despliega en:

https://err4tico-oss.github.io/la-decision-del-gol

> Si en GitHub no aparece la publicación, entra a Settings > Pages y selecciona "GitHub Actions" como fuente.
